# hermes-tweet

## Installation

```bash
claude plugin marketplace add langburd/agent-skills
claude plugin install hermes-tweet@langburd
```

Use [Hermes Tweet](https://github.com/Xquik-dev/hermes-tweet) as a Hermes Agent X/Twitter plugin with read tools, action tools that stay explicitly gated, and bundled skill guidance.

## What You Get

| File | Role |
| --- | --- |
| `skills/hermes-tweet/SKILL.md` | Workflow guidance for installing, configuring, and using Hermes Tweet safely. |
